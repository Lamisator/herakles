Backups that carry the weight.

Herakles backs up your files, folders and whole disks into deduplicated, compressed and AES‑256 encrypted repositories, on a USB disk, your NAS, an SFTP server or its own backup server. One small program, no dependencies, set up in minutes.

Why Herakles

Everything a backup needs, nothing it doesn't

Herakles is a single static program. It contains the scheduler, the user interfaces and even the backup server, so there is nothing else to install, and it works the same on a laptop, a server and a NAS.

Encrypted end to end

AES‑256‑GCM for all data and metadata. Unlock with a password, a key file, or both. Storage and backup server never see your data.

Deduplicated and compressed

Content‑defined chunking stores every piece of data once, across files, snapshots and computers. zstd compression on top.

Full, incremental, differential

Pick a type per schedule, for example full on Sunday and incremental on weekdays. Every snapshot is complete and restorable on its own.

Schedules and retention

Cron schedules, catch‑up of missed runs, retries and rules like “keep 7 daily, 4 weekly, 12 monthly”. Configurable all the way.

Files and whole disks

Back up folders with permissions and metadata, or image entire disks and partitions and write them back for disaster recovery.

Store it anywhere

Local disk, mounted NFS/CIFS share, Windows UNC path, SMB without mounting, SFTP, or the Herakles repository server.

Ransomware‑resistant server

The optional backup server has users, per‑user repositories, quotas and an append‑only mode: clients can add backups but never delete them.

Databases and Docker

PostgreSQL, MySQL/MariaDB, MongoDB and SQLite are dumped while they run and restored with one click. Every Docker Compose project is its own backup, restorable even onto a fresh host.

Web interface with passkeys

On a server, sign in from anywhere with a password or a passkey. Accounts with roles, no public sign-up.

Manage all servers in one place

Attach servers to a hub with a one-time enrollment code. Set up their backups with the wizard, see their disks and restore, all from the hub; shared repositories bring their passwords along.

Four ways to use it

Command line, a full‑screen terminal UI, a desktop GUI and a tray icon, all in the same program and all editing the same YAML file.

See it

Built for people who don't want to think about backups

Set it up once with the desktop interface, then let it run quietly in the tray. When you need something back, browse any snapshot like a folder.

Browse and restore any snapshot

Every backup appears as a complete snapshot. Open it in the explorer, switch between versions, search by name, preview text and pictures, and tick what you need: restore it to the original place or somewhere else, or download it as ZIP or tar.gz. You can also compare two snapshots.

  • Search for a file across all snapshots
  • Choose how to treat existing files
  • Optional verification after restoring

Your Docker projects, one by one

Herakles finds every Docker Compose project on the host and backs each one up as its own snapshot: project directory, bind mounts, volumes and consistent dumps of Postgres, MySQL/MariaDB and MongoDB. Restoring a project stops it, puts back its data, starts it and loads the dumps, and rolls back by itself if anything goes wrong.

How it works →

Jobs, schedules and retention in one form

Pick folders or disks, exclusions, when to run which kind of backup and how long to keep what. Presets cover the common cases. Behind the form is a plain YAML file you can also edit by hand.

Quietly in your tray

herakles tray runs the scheduler and the interface in the background and puts an icon in the system tray. A coloured dot tells you when a backup runs, when a repository needs its password or when something failed. One setting starts it every time you log in.

A command line that scripts well

Everything the interfaces do is also a command: with --help and examples on every command, --json output and meaningful exit codes. Ideal for servers, cron and automation.

Get going

Your first backup in three steps

The guide walks through it in detail, including the command line way.

Download and start

Download the file for your system and start the desktop interface.

herakles tray --open

Follow the wizard

Click New backup: choose what to back up, where to (a USB disk, your NAS, a server), when and for how long.

Done

The wizard creates the encrypted repository, saves the job and starts the first backup. From then on it runs on schedule.

# download (pick the file for your CPU), check it, install it
curl -LO https://herakles.kloeck-it.de/downloads/herakles-linux-amd64

sudo install -m 755 herakles-linux-amd64 /usr/local/bin/herakles
